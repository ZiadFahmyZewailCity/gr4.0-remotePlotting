# (UNDER DEVELOPMENT) Remote Browser Plotting/Interaction OOT module for GNU radio 4.0 

A successor to gr-bokehgui out-of-tree (OOT) module developed as part of google summer of code (GSoC) 2017 by Kartik Patel for GNU Radio 3.x

This module is meant to allow for remote browser based plotting/interaction with GNU Radio 4.0 flowgraphs through sinks and widgets

**Current status** This project is being developed by Ziad Haithem Fahmi as part of **(GSoC) 2026**.
